# VR Networking Technologies Training Simulator

An interactive Virtual Reality educational application developed in Unity to teach computer networking fundamentals through hands-on practice. Created as a Bachelor's diploma project.

## Overview
The simulator allows students to configure network infrastructure in a virtual environment without the need for expensive physical hardware. Users can physically connect devices, visually observe how data packets travel across the network and in future configure network switches via a virtual command-line interface.

## Key Features
- **Dynamic Cable Physics:** Realistic physical simulation of network cables with interactive plugging/unplugging mechanics.
- **Network Packet Visualization:** Real-time visual representation of packet transmission, routing, and connection states between nodes.
- **VR Interaction & Spatial UI:** Intuitive object manipulation and diegetic interfaces designed for comfortable VR learning.

## Tech Stack
- **Engine:** Unity (C#)
- **VR Framework:** XR Interaction Toolkit

## 🚀 How to Run
1. Clone the repository: `git clone (https://github.com/Kreton16/NULP-Diploma.git)`
2. Open the project in Unity Hub (Unity version `6000.6.7f1`).
3. Open the main scene located in `Assets/Scenes/...` and press Play (or build for your VR headset).
